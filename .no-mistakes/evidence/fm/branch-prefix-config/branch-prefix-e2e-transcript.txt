=== End-to-end demo of the configurable ship-branch prefix (branch fm/branch-prefix-config) ===
Run against the worktree checkout at HEAD (2df387e), with a scratch firstmate home.
Every command shown was executed for real; output is verbatim.

=== 1. The captain's registry (data/projects.md in the demo home) ===

- upstream-lib [local-only branch=contrib/] - a third-party repo that must not read as firstmate-authored (added 2026-09-23)
- bare-branch-lib [direct-PR branch=] - ships on a bare task-id branch (added 2026-09-23)
- legacy-lib - default posture, no prefix recorded (added 2026-09-23)

=== 2. Firstmate resolves the registered prefix at task intake (fm-project-mode.sh --branch-prefix) ===

$ for p in upstream-lib bare-branch-lib legacy-lib; do ...; done
upstream-lib: mode+yolo=[local-only off] branch-prefix=[contrib/]
bare-branch-lib: mode+yolo=[direct-PR off] branch-prefix=[]
legacy-lib: mode+yolo=[no-mistakes off] branch-prefix=[fm/]

The token is order-independent, an empty branch= resolves to "" (bare <task-id> branch),
an unannotated project keeps the legacy fm/, and the default "<mode> <yolo>" output that
existing mechanical callers consume is unchanged for every project.

=== 3. Scaffold a ship task with the resolved override (local-only mode shown) ===

$ FM_HOME=<home> bin/fm-brief.sh task-e2e some-proj --mode local-only --branch-prefix 'contrib/'
scaffolded: <home>/data/task-e2e/brief.md (ship, mode=local-only; replace {TASK} and {FIRSTMATE_SPEC})

Branch references in the generated brief (verbatim grep):
22:1. First action: create your branch: `git checkout -b contrib/task-e2e --`
25:1. Never push to any remote and never open a PR. Work only on your `contrib/task-e2e` branch; firstmate handles the merge into local `main`.
78:Ship branch: contrib/task-e2e
80:The task is complete only when committed on your branch `contrib/task-e2e`. Do NOT push, do NOT open a PR, do NOT merge.
83:When it is implemented and committed, append `done [at=<epoch>]: ready in branch contrib/task-e2e` to the status file and stop.

The override renders in every generated section: branch-creation command, never-push rule,
status line, definition-of-done text, and status-message text. No fm/task-e2e remains.

=== 6. Misuse is refused loudly ===

$ bin/fm-brief.sh scout-task some-proj --scout --branch-prefix contrib/
error: --branch-prefix applies only to ship briefs; a scout makes no branch and a secondmate charter is not a delivery contract  (exit 1)

$ bin/fm-brief.sh bad-task some-proj --mode no-mistakes --branch-prefix 'bad prefix/'
error: --branch-prefix must not contain a space (got 'bad prefix/')  (exit 1)
